# Official blind-run intake

The parent agent owns these files. An official child receives only a desired
outcome, a fresh disposable project copy, a real pseudo-TTY requirement, safe
data constraints, progress checkpoints, and a cleanup boundary. It receives
no repository documentation, thesis, README, work packet, source, harness, or
command sequence. The parent writes the returned report here and redacts
machine-specific details before committing.

Cross-scenario comparison and successor candidates are recorded in
[`../../comparison.md`](../../comparison.md). Parent baselines establish that the
underlying path was operable before blind delegation; they are not counted as
child acceptance records.
