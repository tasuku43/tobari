or scored.

  path to be frozen before renderer implementation

## Semantic eligibility

- [ ] The answer and exact Next are available from one status invocation.
- [ ] Routine success requires zero undeclared joins, parsers, provider
      notation, source inspection, or exploratory calls.
- [ ] Stable Context/Workspace/Runtime/policy/attachment identities are validated
      and preserved wherever the complete result includes them.
- [ ] Project root and same-root scope remain explicit when siblings are empty.
- [ ] Absent Workspace, explicit zero counts, synthetic Context null ID,
      unavailable observations, bounded coverage, unparsed evidence, and
      adoption pending remain distinct.
- [ ] Same-name Contexts, sibling order, attached sibling proximity, headings,
      color, indentation, and external prompt-like strings create no selection,
      authority, readiness, login-validity, or Next inference.
- [ ] Recovery obeys executable Catalog grammar; `continue_attached` is an
      explicit non-command action rather than missing recovery.

## Security and execution boundary

- [ ] Fixtures and evidence are synthetic and public-safe.
- [ ] Artifact paths are repository-rooted regular files reached without
      symbolic links.
- [ ] Any subprocess has fixed purpose/argv, finite timeout and output, private
      temporary storage, and no inherited secrets.
- [ ] Fixture/golden generation uses no network or live model.
- [ ] Deterministic fixture/schema checks remain in `task check`; any optional
