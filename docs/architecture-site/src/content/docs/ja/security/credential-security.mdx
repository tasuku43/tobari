---
title: credential security
description: standard の Workspace ネイティブ認証における security の保証と限界です。
---

## release surface が保護するもの

- host credential file、Keychain、SSH agent、credential environment を Workspace
  に mount または copy しません。
- Workspace ごとに独立した永続 home を持ちます。
- 認証情報と cookie は OPA input、audit、denial output、log に入りません。
- allow request は policy 後だけ元の認証情報を受け取り、deny request は upstream
  connection を実行しません。
- release Gateway image と Compose topology に Tobari 所有の認証 command や
  credential service はありません。

## release surface が保護しないもの

同じ Workspace 内の全プロセスは native tool credential を読めます。Tobari は
認証を実行した process の識別、すでに許可された capability の利用防止、provider
session の remote revoke、provider 所有 credential file や account metadata の解釈を
行いません。

## lifecycle

native credential state は Workspace home に属するため、`exit`、runtime rebuild、
container recovery 後も残ります。`tobari delete` はその home を削除します。別の
Workspace では別の native login が必要です。
