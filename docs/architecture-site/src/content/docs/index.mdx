## The operation in 30 seconds

<ol class="home-flow" aria-label="Tobari review flow">
  <li>
    <strong>Enter a Workspace</strong>
    <span>
      The current directory selects a project root and Context-bound logical
      Workspace.
    </span>
  </li>
  <li>
    <strong>Let the agent work</strong>
    <span>
      Its HTTP and HTTPS clients use Gateway; direct external routing is absent.
    </span>
  </li>
  <li>
    <strong>An undeclared request is denied</strong>
    <span>OPA returns default deny and Gateway does not connect upstream.</span>
  </li>
  <li>
    <strong>Review it on the trusted host</strong>
    <span>
      Secret-free retained evidence identifies the exact effect with an opaque
      reference.
    </span>
  </li>
  <li>
    <strong>Allow or deny the exact effect</strong>
    <span>The complete policy is validated and activated atomically.</span>
  </li>
  <li>
    <strong>Retry deliberately</strong>
    <span>Gateway never replays the denied request for you.</span>
  </li>
</ol>

## What the boundary protects—and what it does not

<div class="boundary-comparison home-boundaries">
  <section class="protects">
    <h3>Protected in the supported topology</h3>
    <ul>
      <li>Host files outside the selected project mount</li>
      <li>Docker control and its socket</li>
      <li>Another Workspace’s network and home</li>
      <li>Unauthorized direct external communication</li>
      <li>Broker-managed primary credentials</li>
    </ul>
  </section>
  <section class="does-not-protect">
    <h3>Intentionally not protected</h3>
    <ul>
      <li>Files inside the selected project root</li>
      <li>Data sent to a destination you explicitly allow</li>
      <li>Processes from one another inside the same Workspace</li>
      <li>
        A compromised Docker Engine, host, kernel, Gateway, OPA, or Auth Broker
      </li>
      <li>Protocols other than ordinary HTTP and HTTPS</li>
      <li>File changes across overlapping project roots</li>
    </ul>
  </section>
</div>

Read [Guarantees and limitations](./security/guarantees-and-limitations/) before treating any item as a security claim.
